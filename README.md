# RAGUL — Cinematic Portfolio

A responsive black-and-red portfolio built with React, Vite, Framer Motion and Lucide icons.

## Run locally
1. Install Node.js 20 or newer.
2. Open this project folder in VS Code or a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Production check
Run `npm run build`. Vite writes the production website to `dist/`.

## Deploy with Vercel
Import the GitHub repository into Vercel and keep these settings:
- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`

## Edit your portfolio
- Hero portrait: `public/images/ragul-walking.png`
- Text, skills, projects and links: `src/main.jsx`
- Design and responsive layout: `src/style.css`
